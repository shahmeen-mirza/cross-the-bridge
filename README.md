# Cross the Bridge To Find Treasure Game 
A choice-based adventure game built using Python. Players must navigate through different choices, manage health points, and avoid hidden traps to successfully cross the bridge and find the hidden treasure!

### Core Features:
* 🏞️ Dynamic lake paths (Across vs Around the Lake)
* ⏱️ Real-physics scenarios (Diving under surface waves vs fighting them)
* 🪤 Environmental hazards (Hidden mud swamps, witch spells, and crocodiles)
* ❤️ Advanced 100 HP tracking with custom damage limits
* 🚀 Fully operational game replay loop system
